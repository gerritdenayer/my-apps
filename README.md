# My Apps

My personal collection of HTML apps, hosted for free on GitHub Pages.

## How this works

- Every app lives in its own folder under `apps/`
- `index.html` in the root is the landing page that lists all apps
- GitHub Pages turns this repo into a live website automatically

## Adding a new app

1. Create a new folder under `apps/`, for example `apps/my-new-app/`
2. Put an `index.html` file in it (plus any other files the app needs)
3. Add a card for it on the landing page (`index.html` in the root)
4. Commit and push, the site updates within a minute or two

## Folder structure

```
my-apps/
├── index.html          <- landing page listing all apps
├── README.md           <- this file
└── apps/
    └── hello-world/    <- one folder per app
        └── index.html
```
